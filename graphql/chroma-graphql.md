# Chroma GraphQL API

Chroma is an open-source embedding database for AI. The API covers collection management, document and embedding upsert, querying by embedding or text, metadata filtering, and multi-modal data storage.

**Endpoint:** No native GraphQL endpoint — conceptual schema derived from Chroma REST/gRPC API
**Documentation:** https://docs.trychroma.com/reference/chroma-reference
